# Bug Report Template (Max 12 Lines)

Use this concise template when reporting unresolved issues or escalation findings:

```markdown
- **Symptom**: <Concise description of the observed defect>
- **Reproduction**: Seed: `<seed>`, Actions: `[<actions>]`, Viewport: `<WxH>`
- **Expected**: <Behavior according to spec>
- **Actual**: <Observed incorrect behavior>
- **Root Cause**: <Two-sentence explanation of why the defect occurs>
- **Attempted Fixes**: <1. Tried X (result Y), 2. Tried Z (result W)>
- **Proof / Regression Test**: `tests/regression_<cause>.test.ts`
- **Escalation Reason**: <Need owner decision on feel / locked rule / 3 failed attempts>
```
